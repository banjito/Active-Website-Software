A procedure documents how a test is performed. Two technicians following the same procedure should get the same answer, and that is the whole point.

## Where they are

**Lab → Testing procedures.**

## Creating one

1. Click **New procedure**.
2. Title it for what it covers, such as `Insulation Resistance, Dry Type Transformers`.
3. Reference the applicable standard clause.
4. Write the procedure.
5. Save, and route it for approval.

## What a good procedure contains

| Section | Says |
|---|---|
| **Scope** | What equipment and conditions this covers |
| **Standard reference** | The clause it implements |
| **Safety** | PPE, de-energization, grounding |
| **Equipment required** | Which instruments, and their required accuracy |
| **Method** | The steps, in order |
| **Acceptance criteria** | What passes, what fails |
| **Recording** | Which report form and which fields |

::: tip
The **recording** section is the one people leave out and the one that saves the most time. Naming the exact report form removes the daily question of which one to use.
:::

## Revisions and approval

Procedures are controlled documents. When one changes:

1. Create a new revision rather than editing in place.
2. Note what changed and why.
3. Route it for approval.
4. Supersede the old revision. Do not delete it.

Keeping superseded revisions is what lets you answer "which version was in force when this test was performed?" That question only comes up during an audit or a dispute, and it is not one you want to guess at.

::: warning
Editing a procedure in place destroys the record of what people were actually working to at the time. Always revise, never overwrite.
:::

## Linking procedures to reports

Where a procedure corresponds to a specific report type, note it in both directions: the procedure names the form, the form's guidance names the procedure.

New technicians find this pairing more useful than either document alone.

## Keeping them honest

The failure mode for procedures is drift: the written procedure says one thing, the crew does another, and nobody notices for two years.

Two habits prevent it:

1. **Ask during review.** When reviewing reports, occasionally check that what was done matches what the procedure says.
2. **Update when practice changes for a good reason.** If the crew found a better method, the procedure should say so. A procedure nobody follows is worse than none, because it is evidence you are not doing what you documented.
