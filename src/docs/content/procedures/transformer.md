## Purpose

Outline the procedure for testing a transformer to meet the NETA ATS (Acceptance Testing
Specifications) standards, so the transformer is tested comprehensively and meets the
specified performance criteria.

## Scope

Testing of transformers in accordance with the NETA ATS standards. It covers the steps and
guidelines to be followed by qualified personnel to ensure accurate and reliable testing.

## Safety and precautions

::: danger
Ensure that the transformer is properly de-energized and disconnected from the power source
before initiating any testing procedures, and follow proper lockout/tagout procedures to
prevent accidental energization. Ground and discharge the windings between tests: a
transformer holds a charge.
:::

- Adhere to all relevant safety regulations and wear appropriate personal protective
  equipment (PPE) during the testing process.

## Equipment and tools

- Megohmmeter
- Power factor test set
- Excitation test set
- Turns ratio meter
- Transformer winding resistance test set
- Oil test kit (if applicable)
- Multimeter
- Test leads and cables
- Safety barriers and signs
- Personal protective equipment (PPE)

## Procedure

::: note
Ensure that all equipment used for testing is properly calibrated and maintained.
:::

### 1. Preparation

1. Review the transformer's specifications, drawings, and nameplate details.
2. Verify that the testing equipment is in good working condition and properly calibrated.
3. Assemble all necessary tools, equipment, and PPE required for testing.
4. Ensure that the testing area is clear of any potential hazards and properly marked with
   safety barriers and signs.

### 2. Visual inspection

1. Inspect the transformer for any physical damage, loose connections, or signs of
   overheating.
2. Check for oil leaks (if applicable) and inspect the condition of the insulating oil.
3. Verify that the cooling system is functioning properly.

### 3. Insulation-resistance test

1. Use a megohmmeter or insulation-resistance tester to measure the insulation resistance of
   the transformer windings.
2. Follow the manufacturer's instructions and record the insulation-resistance readings.
3. Compare the readings with the specified minimum values as per NETA ATS standards. Any
   deviations should be noted and investigated further.

### 4. Power factor

1. Use a power factor test set to perform a power factor test on the primary and secondary
   sides of the transformer. Confirm correct test voltages before performing the test.
2. Record the measured values.
3. Analyze the results.

### 5. Excitation

1. Use an excitation test set to measure the exciting current.
2. Record the measured values.
3. Analyze the results.

### 6. Turns ratio test

1. Use a turns ratio meter on the primary and secondary windings of the transformer.
2. Record the turns ratio value on each tap.
3. Compare the measured turns ratio with the specified turns ratio as per NETA ATS standards.
   Any significant deviations should be investigated further.

### 7. Winding resistance test

1. Use a transformer winding test set to measure the resistance of each transformer winding.
2. Record the resistance values for each winding on each tap.
3. Compare the measured winding resistance values with the manufacturer's specifications or
   the expected values as per NETA ATS standards.
4. Demagnetize the transformer.

::: warning
Do not leave a transformer magnetized. Demagnetizing after winding resistance testing is the
last step, and skipping it can cause nuisance inrush trips at energization.
:::
